# Документация CubeSat 1U системы

## Обзор

Это главная страница документации для CubeSat 1U системы - упрощенной, оптимизированной версии для ресурсоограниченных сред с фокусом на надежность и эффективность.

## Структура документации

### [API](api/API.md)
Документация по API системы, включая протоколы связи, форматы сообщений и интерфейсы.

### [Архитектура](architecture/)
- [Общая архитектура](architecture/ARCHITECTURE.md) - Общее описание архитектуры системы
- [Новая архитектура](architecture/NEW_ARCHITECTURE.md) - Описание новой улучшенной архитектуры
- [Улучшения](architecture/IMPROVEMENTS.md) - Подробное описание всех улучшений

### [Железо](hardware/)
- [Arduino интеграция](hardware/ARDUINO_INTEGRATION.md) - Документация по Arduino комплектации и подключению датчиков

### [Развертывание](deployment/DEPLOYMENT.md)
Документация по развертыванию системы, включая требования, установку и запуск.

### [Безопасность](security/SECURITY.md)
Документация по системе безопасности, включая аутентификацию, шифрование и защиту данных.

### [Тестирование](testing/TESTING.md)
Документация по тестированию системы, включая unit-тесты, интеграционные тесты и тесты производительности.

### [Мониторинг](monitoring/MONITORING.md)
Документация по системе мониторинга и логирования, включая алерты и уведомления.

### [Обновления "на лету"](ota/OTA.md)
Документация по системе обновлений "на лету", включая безопасность и откат обновлений.

### [Docker](docker/DOCKER.md)
Документация по контейнеризации системы с использованием Docker и Docker Compose.
