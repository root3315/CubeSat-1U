# Новая архитектура CubeSat 1U системы

## Обзор системы

CubeSat 1U система состоит из трех основных компонентов:

```
┌──────────────────┐     ┌──────────────────┐     ┌──────────────────┐
│   STM32F0        │     │  Raspberry Pi    │     │  Ground Station  │
│   (C/FreeRTOS)   │───▶│  Zero 2 W        │────▶│  (Streamlit)     │
│                  │ UART│  (Python)        │ UDP │                  │
└────────┬─────────┘     └────────┬─────────┘     └──────────────────┘
         │                        │                        │
         ▼                        ▼                        ▼
      Sensors                  Camera                    User
      • LIS3MDL                • 8MP                    • Display
      • BME280                 • SVD Comp.              • Commands
      • TMP117                 • SD Card                • Export
      • MCP3008                • Security
      • SBM-20                 • Monitoring
                              • Resource Optimization
```

## Компоненты системы

### 1. STM32 Firmware (C/FreeRTOS)
- **Ответственность**: Чтение датчиков в реальном времени, подсчет радиации, UART связь
- **Язык**: C с использованием FreeRTOS
- **Функции**:
  - Чтение показаний с датчиков (I2C, SPI, ADC)
  - Подсчет импульсов радиации
  - Отправка телеметрии через UART
  - Прием команд от Raspberry Pi

### 2. Raspberry Pi Code (Python)
- **Ответственность**: Управление камерой, сжатие изображений, логирование, UDP связь, безопасность, мониторинг
- **Язык**: Python 3
- **Основные модули**:

#### Flight Controller
- Главный контроллер полета
- Управление всеми процессами
- Обработка команд и телеметрии
- Мониторинг состояния системы

#### Communication Handler
- Обработка всех каналов связи
- UART (STM32)
- UDP (наземная станция)
- Обработка команд и данных

#### Security Manager
- Аутентификация команд
- HMAC подписи
- Управление одноразовыми числами (nonce)
- Валидация временных меток

#### Camera Handler
- Управление камерой
- Съемка изображений
- Сжатие SVD
- Создание миниатюр

#### Telemetry Handler
- Обработка и хранение телеметрии
- Архивация данных
- Очистка старых файлов

#### OTA Updater
- Обновления "на лету"
- Резервное копирование
- Проверка целостности

#### Logging & Monitoring
- Упрощенное логирование
- Мониторинг ресурсов
- Алерты и уведомления

### 3. Ground Station (Python/Streamlit)
- **Ответственность**: Визуализация телеметрии, отправка команд, экспорт данных
- **Язык**: Python/Streamlit
- **Функции**:
  - Визуализация графиков телеметрии
  - Интерфейс отправки команд
  - Просмотр изображений
  - Экспорт данных

## Протоколы связи

### UART (STM32 ↔ Raspberry Pi)
- Скорость: 115200 бод
- Пакет телеметрии: 40 байт
- Пакет команды: переменная длина

### UDP (Raspberry Pi ↔ Ground Station)
- Порт: 5000
- Формат: JSON
- Безопасность: HMAC подписи

## Безопасность

### Аутентификация команд
- HMAC-SHA256 подписи
