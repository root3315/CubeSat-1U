# Документация по развертыванию CubeSat 1U

## Подготовка к развертыванию

### Требования к оборудованию
- Raspberry Pi (рекомендуется Zero 2 W или выше)
- Датчики (LIS3MDL, BME280, TMP117, MCP3008, SBM-20)
- Камера (если требуется)
- UART/USB интерфейс для связи с STM32

### Требования к программному обеспечению
- Python 3.9+
- pip
- git (для клонирования репозитория)

## Установка

### Клонирование репозитория
```bash
git clone <repository-url>
cd CubeSat-1U
```

### Установка зависимостей
```bash
cd raspberry-pi-code
pip3 install -r requirements.txt
```

### Генерация ключей безопасности
```bash
python3 ../generate_keys.py
```

## Конфигурация

### Основные параметры (config.json)
- `satellite`: Информация о спутнике
- `camera`: Параметры камеры
- `storage`: Настройки хранения данных
- `communication`: Параметры связи
- `security`: Настройки безопасности
- `logging`: Параметры логирования
- `power_management`: Управление питанием

### Пример конфигурации
```json
{
  "satellite": {
    "name": "CubeSat-1U",
    "mission_id": "CS1-2025",
    "callsign": "CS1"
  },
  "power_management": {
    "low_power_mode_enabled": true,
    "low_battery_threshold": 3.6,
    "power_save_intervals": {
      "normal": 60,
      "low_battery": 300,
      "critical_battery": 600
    }
  }
}
```

## Запуск системы

### Запуск контроллера полета


## Режимы работы

### Симуляция (без оборудования)
Система может работать в режиме симуляции для тестирования. В этом режиме:
- Используются фиктивные датчики
- Имитируется работа оборудования
- Можно тестировать логику и интерфейсы

### Рабочий режим
В рабочем режиме система:
- Взаимодействует с реальным оборудованием
- Собирает реальные данные
- Выполняет команды от наземной станции

## Безопасность

### Аутентификация команд
Все команды от наземной станции должны быть:
- Подписаны HMAC-подписью
- Содержать одноразовое число (nonce)
- Иметь действительную временную метку

### Шифрование
Данные могут быть зашифрованы при необходимости.

## Мониторинг и диагностика

### Логи
- Основные логи: `logs/cubesat.log`
- Алерты: `logs/cubesat_alerts.log`
- Телеметрия: сохраняется в указанной директории

### Диагностика
Для диагностики используйте:
- Команды проверки статуса
- Веб-интерфейс наземной станции
- Логи системы

## Управление питанием

Система автоматически:
- Отслеживает уровень заряда батареи
- Переходит в режим энергосбережения при низком заряде
- Адаптирует частоту опроса датчиков

## Обновления "на лету" (OTA)

Система поддерживает обновления:
- Без остановки работы
- С возможностью отката
- С проверкой целостности

## Устранение неполадок

### Проблемы с подключением
- Проверьте настройки портов
- Убедитесь, что оборудование подключено
- Проверьте права доступа к портам

### Проблемы с производительностью
- Проверьте использование CPU и памяти
- Убедитесь, что система не перегревается
- Проверьте уровень заряда батареи

### Проблемы с безопасностью
- Убедитесь, что ключи безопасности сгенерированы
- Проверьте срок действия сертификатов
- Убедитесь, что команды правильно подписаны

## Резервное копирование

Система автоматически:
- Создает резервные копии конфигурации
- Архивирует старые логи
- Сохраняет критические данные
