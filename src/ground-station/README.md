# CubeSat 1U Ground Station

## Описание
Web-интерфейс для мониторинга и управления CubeSat 1U спутником. Предоставляет визуализацию телеметрии, отправку команд и отображение полученных данных.

## Запуск

### Требования
- Python 3.9+
- Docker (опционально)
- Доступ к CubeSat системе (в режиме симуляции или реальной)

### Установка зависимостей
```bash
cd ground-station
pip install -r requirements.txt
```

### Запуск веб-интерфейса
```bash
cd ground-station
streamlit run ground_station.py
```

По умолчанию интерфейс будет доступен по адресу: http://localhost:8501

## Функциональность

### Визуализация телеметрии
- Графики изменения параметров во времени
- Отображение текущих значений датчиков
- Статус системы и питания

### Управление
- Отправка команд спутнику
- Управление режимами работы
- Настройка параметров системы

### Мониторинг
- Состояние соединения
- Журнал событий
- Алерты и уведомления

## Режимы работы
- **Симуляция**: Работа без реального CubeSat, с генерацией фиктивных данных
- **Реальный режим**: Работа с реальным CubeSat оборудованием

## Безопасность
Интерфейс использует безопасные методы аутентификации и шифрования при взаимодействии с CubeSat системой.

## Техническая документация

### Архитектура
Ground station состоит из следующих компонентов:
- Веб-интерфейс (Streamlit)
- Обработчики команд
- Система визуализации
- Модуль связи с CubeSat

### API
Интерфейс предоставляет REST API для интеграции с другими системами.

## Устранение неполадок

### Если интерфейс не запускается
1. Проверьте, что все зависимости установлены
2. Убедитесь, что порт 8501 (или другой указанный) не занят
3. Проверьте права доступа к файлам

### Если нет данных телеметрии
1. Убедитесь, что CubeSat система запущена и подключена
2. Проверьте сетевые настройки
3. Убедитесь, что используется правильный режим (симуляция/реальный)
