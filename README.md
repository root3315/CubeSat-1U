# CubeSat 1U - Упрощенная версия

## Обзор
CubeSat 1U - это система управления миниатюрным спутником формата CubeSat. Этот проект представляет собой упрощенную, оптимизированную версию для ресурсоограниченных сред с фокусом на надежность и эффективность.

## Запуск

### Требования
- Raspberry Pi (Zero 2 W или выше)
- Python 3.9+
- Необходимые датчики и оборудование

### Установка
```bash
# Установка зависимостей
pip3 install -r src/raspberry-pi-code/requirements.txt

# Генерация ключей безопасности
python3 scripts/generate_keys.py

# Запуск контроллера полета
cd src/raspberry-pi-code
python3 flight_controller.py
```

### Запуск наземной станции
```bash
cd src/ground-station
pip3 install -r requirements.txt
streamlit run ground_station.py
```
